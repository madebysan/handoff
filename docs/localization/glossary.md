# Localization glossary

Use this glossary during Spanish review. If a term is awkward in context, update the glossary and then update the UI copy.

| English | Spanish | Notes |
|---|---|---|
| Handoff | Handoff | Product name. Do not translate. |
| Get Started | Empezar | Short CTA. |
| Save | Guardar | Button label. |
| Load | Cargar | Button label for importing a saved draft file. |
| Save Changes | Guardar cambios | Sidebar action that sends the user to review. |
| Review | Revisión | Use as a noun. Use `Revisar` for the action. |
| Download | Descargar | Use for PDF and Markdown files. |
| Draft | Borrador | Use in explanatory text, not short buttons. |
| Family | Familia | Keep warm and broad. |
| Wishes | Deseos | Avoid overly legal phrasing. |
| Sign & Finish | Firmar y terminar | Section title. |
| Passphrase | Frase personal | Prefer this in user-facing copy unless the exact security term matters. |
| Estate attorney | Abogado de planificación patrimonial | Long but clearer than region-specific alternatives. |
| Power of Attorney | Poder notarial | Mark for review if context requires healthcare vs financial distinction. |
| Advance directive | Directiva anticipada | Mark for regional review. |
| Beneficiary | Beneficiario | Standard financial/legal term. |
| Claim | Reclamo | Neutral Latin American usage for insurance. |
| Co-signed | Cofirmado | Mark for review if a more natural phrase fits the UI context. |
| Safe deposit box | Caja de seguridad | Common financial storage term. |
| Password manager | Gestor de contraseñas | Keep consistent. |
| Two-factor authentication | Autenticación de dos factores | Can shorten to `2FA` in cramped labels only. |
| Cloud storage | Almacenamiento en la nube | Standard UI term. |
