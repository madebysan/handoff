# Spanish style guide

Target Spanish for Handoff is neutral Latin American Spanish with friendly `tú`.

## Voice

- Sound calm, practical, and human.
- Use direct language. Prefer "Guarda", "Descarga", "Revisa", and "Comparte" over formal phrasing.
- Avoid legal certainty. Handoff is a practical guide, not a legal document.
- Avoid dramatic or fear-based wording. The product helps families prepare without making the user feel pressured.
- Keep sensitive health, death, money, and family copy gentle but clear.

## Grammar

- Use `tú`, not `usted`.
- Prefer natural Latin American phrasing over literal English structure.
- Keep commands short on buttons.
- Use sentence case for headings and labels.
- Avoid unnecessary English loanwords when a common Spanish term works.

## UI copy rules

- Buttons should fit small screens first. Prefer one or two words when possible.
- Labels should name the field, not explain it. Put explanation in help text.
- Review and export text should explain the next action, not the internal route name.
- Do not translate stored data values in a way that changes app logic. UI labels can translate, stored values should remain stable.

## Terms that need extra care

- Legal and financial terms should be practical, not overly formal.
- If a legal or financial term feels region-specific, mark it for review in the copy review pack instead of guessing.
- Keep `Handoff` as the product name.
